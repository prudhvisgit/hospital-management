# CareSync - AI-Powered Hospital Management System

CareSync is a comprehensive, scalable, and secure web application designed for modern hospital management. It features AI-driven tools, role-based dashboards, and a premium user experience.

## ✨ Key Features

- **🤖 AI-Powered Diagnostics**: Symptom checker, medical report summarizer, and health chatbot.
- **📅 Smart Appointments**: Instant booking with automated doctor assignment logic.
- **🏥 Role-Based Dashboards**: Tailored experiences for Patients, Doctors, and Administrators.
- **📞 Telemedicine**: Secure video consultations and real-time chat.
- **📁 Digital Medical Records**: Secure, paperless management of prescriptions and reports.
- **🆘 Emergency Mode**: Instant activation with destructive UI feedback for critical situations.

## 🚀 Tech Stack

- **Frontend**: Next.js 15, TypeScript, Tailwind CSS, Lucide Icons, Sonner.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), JWT.
- **UI Components**: Radix UI / Headless UI with custom styling.

## 📥 Getting Started

### Local Development

1. **Backend**:
   ```bash
   cd backend
   npm install
   # Configure .env based on .env.example
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
